# Evaluation protocol

- **Primary opponent:** the actual public Blueprint Linux executable, pinned to commit `ba64c267aa2e8c442e5e5f824539c400faea7a64`. **Second opponent:** the actual public RangeRunner executable with its native evaluator, commit `f452b09e8ebd6fd6eb9d17035f41e5b626712fcb`.
- **Objective:** beat both in chips and official match points, record zero losses against each in independent tests, and measure field points. The reported tournament leader's 21.25/25 makes the aspirational target 24.25/25. Do not confuse independently measured public results with the official leaderboard.
- **Development:** use separate seeds to train, identify betting styles, compare checkpoints, and select experts. The large GPU checkpoint is compared with the prior one on common opponent images and deals. The field rules only enable a model if chip return improved on all three development fixtures, match points did not worsen, there was at least one fault-free pair, and mean improvement exceeded 0.35 BB per duplicate deal.
- **Confirmation:** freeze one runnable archive and use exactly that image on both 40-match holdouts and the public field. Both versions get the same 1,000 deals per match, with each deal replayed from the opposite seat. Compare wins, draws and losses alongside the expected chip return. Preserve every result. If the zero-loss objective fails, record that explicitly; do not remove a seed or add matches to dilute a loss.
- **Field:** count distinct public team programs separately from duplicate starter copies, dummy bots and the inaccessible historical snapshot. For the 25-team stress test, select the hardest current public teams by Weights 2's screening chip margin, then evaluate on **two different, fresh matches per team**. A win is one point and a draw half a point; divide total points over 50 matches by two for a score out of 25. The real 26-bot contest roster, its unpublished versions and particular deals may differ.
- **Verification:** the actual match process is CPU-only, runs under the referee clock with no Internet, resets between seat-swapped halves, and reports defaults or timeouts. Recompute each match verdict from all 1,000 raw duplicate-deal returns. Report any opponent clock problems when interpreting field improvements.
