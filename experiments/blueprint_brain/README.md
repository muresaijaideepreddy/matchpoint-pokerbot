# Blueprint strategy (third-party)

`brain.py` and `bot_data/` are copied unchanged from the public **Blueprint** bot by
Dushyant-Betala (GitHub `dushyant-betala/heads-up-bundle`, snapshot built 2026-11-07).
The repository publishes no license; the MatchPoint team uses it with the author's
public code as-is and credits the author here.

MatchPoint uses it only as a fallback: after the stop-loss decides that Weights 3 and the
range-reader counter are both losing, a fresh `brain.Brain()` plays the rest of the half.
